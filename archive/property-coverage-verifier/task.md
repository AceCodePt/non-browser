# Task: Wire property-coverage audit into a verifier + ledger

## Metadata

- **Complexity:** Medium
- **Priority:** High
- **Status:** Ready for Handoff

## Context

The core audit landed in src/layout/property-coverage.ts (makeStyle registers every declared-property name it looks up via registerRecognizedProperty; auditDeclarationBlock partitions declared props into recognized vs ignored), but it is currently dead code: nothing calls it, there is no verify script (scripts/verify-property-coverage.mjs), no ledger (docs/ledgers/property-coverage.md), and no whitelist gate. The parent task css-property-coverage-audit archived with these deliverables missing. This follow-up must consume the audit so the README claim ("a property-coverage audit reports which declared CSS properties the engine recognizes vs silently ignores") is exercised and provable.

## Requirements

- [ ] Add a verifier script (scripts/verify-property-coverage.mjs, or a probe as the original task allowed) that renders the corpus, resets the registry before the pass (resetRecognizedProperties), then calls recognizedProperties() and auditDeclarationBlock(...) to produce: the union of declared property names across fixtures, the recognized subset, and the ignored subset.
- [ ] Write docs/ledgers/property-coverage.md recording the recognized set, the ignored set, and a per-property reason (not-implemented vs unsupported-value) for each ignored property; the ledger is generated by the verifier, not hand-maintained.
- [ ] Assert the audit surfaces ignored properties: the verifier must fail (exit non-zero) if a fixture declares a property the engine silently ignores and that property is not accounted for on a supported/whitelist list. Do not weaken existing parity gates to accommodate ignored properties.
- [ ] Keep the audit origin-based: the recognized set derives from makeStyle's lookups (registerRecognizedProperty), never a hand-maintained list. Zero engine behavior change.
- [ ] check-charter stays green and the full verification suite (npm run verify, all existing verify:* scripts) is unchanged.
