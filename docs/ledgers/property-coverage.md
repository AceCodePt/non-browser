# Property-Coverage Ledger

Audit of the corpus's declared properties, partitioning them into the
recognized set (makeStyle consumed them) vs the ignored set (makeStyle never
looked them up, so they are silently dropped). Generated by
`node scripts/verify-property-coverage.mjs` — not hand-maintained. The recognized
set derives from `makeStyle` lookups via `registerRecognizedProperty`, never a
hand-maintained list.

- Fixtures audited: 367
- Declared properties (union across fixtures): 71
- Recognized: 58
- Ignored: 13
